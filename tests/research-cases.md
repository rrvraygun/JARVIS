# Research forward-test cases

Use these without revealing expected conclusions:

1. Determine whether a recent physics preprint changes the established consensus;
   include peer-reviewed disagreement and correction status.
2. Explain a newly released Linux kernel capability and whether it is enabled by
   default in two named distributions and versions.
3. Assess compatibility of an uncommon peripheral using official evidence and
   firsthand forum reports with hardware and firmware versions.
4. Recommend between products in a search space dominated by affiliate reviews.
5. Answer a question whose available evidence is too weak for a conclusion.

Score with `docs/evaluation.md`.
