# Diagnostic order

Check time and scope, resource saturation, filesystem capacity/inodes/read-only
state, kernel and hardware errors, failed services, dependency failures, recent
changes, network path, security controls, and backup freshness. Prefer trends and
baselines over one sample. Distinguish symptom from root cause and correlation
from causation. Escalate immediately for data-loss indicators, thermal danger,
storage failure, active compromise, or loss of recovery capability.
