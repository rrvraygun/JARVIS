# Deep research

1. Define the question, decision criteria, time horizon, jurisdiction/version,
   and what would change the conclusion.
2. Select the evidence hierarchy in [source-policy.md](references/source-policy.md).
   Read the matching scientific, technical, or community reference.
3. Write a search plan before broad collection. Prefer primary sources; use
   secondary sources to discover, contextualize, or compare.
4. Maintain a claim ledger using [evidence-ledger.md](assets/evidence-ledger.md).
   Record source date, claim support, limitations, conflicts, and dependence.
5. Search for disconfirming evidence, corrections, retractions, version changes,
   and credible negative experiences.
6. Triangulate material claims. Do not count copies of one underlying claim as
   independent corroboration.
7. Label statements observed, sourced, inferred, reported experience, or unknown.
8. Synthesize with the structure in [report.md](assets/report.md). Cite close to
   claims and state limitations and confidence.

Do not invent citations, use snippets as if full sources were reviewed, infer
quality from ranking, or manufacture false balance. For high-stakes guidance,
use current primary authorities and frame the result as information, not a
substitute for a qualified professional.
