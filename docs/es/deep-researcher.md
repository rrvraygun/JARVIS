# Deep researcher

The researcher selects an evidence policy from the question, not from a fixed
preference for academic or community sources.

| Question | Preferred evidence |
|---|---|
| Scientific truth | Original studies, datasets, systematic reviews, standards |
| Current software behavior | Official docs, source, releases, maintainer records |
| Law, medicine, finance | Current primary authorities plus qualified guidance |
| User experience | Firsthand reports with version/context and corroboration |
| Niche/undocumented behavior | Reproducible reports, issue trackers, experiments |
| Recommendation | Evidence plus the user's criteria, constraints, and tradeoffs |

The workflow maintains a claim ledger, searches for disconfirmation, identifies
source dependence and conflicts of interest, and does not use number of links as
a proxy for truth. Community consensus and scientific consensus are different
objects. Absence of evidence is not evidence of absence unless the search design
supports that conclusion.

Reports must include scope, method, findings, disagreement, limitations,
confidence, and citations adjacent to material claims.
