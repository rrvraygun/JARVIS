# Índice de documentación de JARVIS

Esta carpeta contiene la documentación española de JARVIS. La versión inglesa
principal se mantiene fuera de docs/es. Los nombres de este árbol están en
español para que las rutas y el contenido coincidan.

## Orden de autoridad

1. AGENTS.md define las invariantes del repositorio.
2. [Estado actual del producto](estado-actual-producto.md) describe el
   comportamiento implementado.
3. Los contratos vigentes definen los límites de cada subsistema.
4. El inventario generado describe archivos; no concede autoridad de ejecución.
5. Las auditorías y sesiones conservan evidencias fechadas.
6. El historial conserva diseños sustituidos y no modifica los contratos actuales.
