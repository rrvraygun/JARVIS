# Investigador profundo

El investigador selecciona una política de evidencia a partir de la pregunta, no de un número fijo.
preferencia por fuentes académicas o comunitarias.

| Pregunta | Pruebas preferidas |
|---|---|
| Verdad científica | Estudios originales, conjuntos de datos, revisiones sistemáticas, estándares |
| Comportamiento actual del software | Documentos oficiales, fuentes, publicaciones, registros de mantenimiento |
| Derecho, medicina, finanzas | Autoridades primarias actuales más orientación calificada |
| Experiencia de usuario | Informes de primera mano con versión/contexto y corroboración |
| Nicho/comportamiento indocumentado | Informes reproducibles, rastreadores de problemas, experimentos |
| Recomendación | Evidencia más los criterios, limitaciones y compensaciones del usuario |

El flujo de trabajo mantiene un libro de reclamaciones, busca desconfirmaciones, identifica
dependencia de fuentes y conflictos de intereses, y no utiliza el número de enlaces como
un sustituto de la verdad. El consenso comunitario y el consenso científico son diferentes
objetos. La ausencia de evidencia no es evidencia de ausencia a menos que el diseño de búsqueda
apoya esa conclusión.

Los informes deben incluir alcance, método, hallazgos, desacuerdos, limitaciones,
confianza y citas adyacentes a afirmaciones materiales.
